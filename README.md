# 💎 TON Transaction Tracker & Watchlist Bot 

Асинхронный Telegram-бот на **aiogram 3** и **TonAPI (v2)** для отслеживания входящих и исходящих транзакций в сети TON в реальном времени с поддержкой вотч-листа, доменов TON DNS, отображением баланса «ДО/ПОСЛЕ», конвертацией в фиатные валюты и монетизацией через **Telegram Stars**.

---

## ✨ Ключевые возможности

* 🔔 **Уведомления о транзакциях в реальном времени:**
  * Поддержка нативных переводов **TON** и токенов **Jetton** (USDT, NOT, DOGS и др.).
  * Наглядное отображение суммы, сетевой комиссии и точного баланса: **ДО** и **ПОСЛЕ** транзакции с индикатором изменения ($\Delta$).
  * Автоматический пересчет суммы перевода в фиатные валюты (**USD**, **EUR**, **RUB**).
* 🚚 **Трекинг доставки исходящих платежей:**
  * При отправке TON бот ставит статус `⏳ Ожидаем зачисления...`, опрашивает кошелек получателя и **автоматически редактирует сообщение** на `✅ Доставлено`, как только средства поступили адресату.
* 🌐 **Поддержка доменов TON DNS и Fragment:**
  * Кошельки можно указывать не только адресом (`EQ...`, `UQ...`, `0:...`), но и доменами: `wallet.ton`, `alice.ton`, `durov.t.me`.
* 🔎 **Инлайн-режим (`@bot address`):**
  * Возможность проверить баланс любого кошелька или домена прямо в чате или группе.
  * Встроена защита от спама API при посимвольном наборе текста и кэширование результатов.
* 👥 **Гибкая система доступа (BYOK + Whitelist):**
  * **Администраторы (`WHITELIST_USER_IDS`):** безлимитный вотч-лист, работа на мастер-ключе бота.
  * **Бесплатные пользователи:** доступ к 1 кошельку со своим бесплатным ключом TonAPI (архитектура *Bring Your Own Key* защищает от исчерпания общих лимитов).
* ⭐ **Монетизация через Telegram Stars:**
  * Встроенная покупка безлимитного вотч-листа за внутреннюю валюту Telegram без сторонних платежных шлюзов:
    * **1 месяц** — `129 ⭐`
    * **1 год** — `999 ⭐`
    * **Навсегда (Lifetime)** — `1499 ⭐`

## 🚀 Быстрый запуск

### Вариант 1: Запуск через Docker Compose (рекомендуется)

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/Fawnv/ton-announcements-tg-bot.git
   cd ton-tracker-bot
   ```

2. **Настройте переменные окружения:**
   ```bash
   cp .env.example .env
   nano .env
   ```
   *Укажите `BOT_TOKEN`, ваш `WHITELIST_USER_IDS` и `TONAPI_KEY`.*

3. **Создайте файл базы данных на хосте (чтобы Docker примонтировал его как файл):**
   ```bash
   touch bot_users.db
   ```

4. **Убедитесь, что внешняя Docker-сеть создана (если используется `web-network`):**
   ```bash
   docker network create web-network || true
   ```

5. **Соберите и запустите контейнер:**
   ```bash
   docker compose up -d --build
   ```

6. **Просмотр логов:**
   ```bash
   docker compose logs -f
   ```

---

### Вариант 2: Локальный запуск (Python)

1. Требуется **Python 3.11+**.
2. Создайте и активируйте виртуальное окружение:
   ```bash
   python3 -m venv venv
   source venv/bin/activate  # Для Linux/macOS
   # venv\Scripts\activate   # Для Windows
   ```
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Заполните `.env` по примеру `.env.example`.
5. Запустите бота:
   ```bash
   python main.py
   ```

## ⚙️ Настройка в Telegram (@BotFather)

1. **Создание бота:**
   * Напишите [@BotFather](https://t.me/BotFather), отправьте `/newbot` и сохраните полученный `BOT_TOKEN`.
2. **Включение инлайн-режима:**
   * Отправьте `/setinline` $\rightarrow$ выберите своего бота.
   * В поле **Placeholder** введите: `Введите адрес или домен .ton...`
3. **Оплата звездами (Telegram Stars):**
   * Никаких платежных провайдеров настраивать не нужно! Telegram Stars работают из коробки с `currency="XTR"`.

## 🔑 Где получить TonAPI Key

* **Мастер-ключ бота:** зарегистрируйтесь на [tonapi.io](https://tonapi.io), перейдите в раздел **TON API $\rightarrow$ API Keys** и скопируйте созданный ключ в переменную `TONAPI_KEY` в `.env`.
* **Бесплатные пользователи:** бот автоматически выдает пошаговую инструкцию со ссылкой на [tonapi.io](https://tonapi.io), чтобы каждый сторонний пользователь подключил свой персональный ключ.

## 📋 Основные команды бота

| Команда | Описание |
| :--- | :--- |
| `/start` | Открыть главное меню, проверить статус подписки и лимиты |
| `/watch <адрес/домен>` | Добавить кошелек (или домен `.ton`) в список наблюдения |
| `/list` | Посмотреть активный вотч-лист, балансы кошельков и управление ими |
| `/cancel` | Сбросить текущее действие или ввод данных |

### Примеры инлайн-запросов (в любом чате):
* `@your_bot` — мгновенно отправить информацию о своем кошельке из вотч-листа.
* `@your_bot UQDNzlh0XSZdb5_Qrlx5QjyZHVAO74v5oMeVVrtF_5Vt1rIt` — карточка кошелька по адресу.
* `@your_bot wallet.ton` — карточка кошелька по доменному имени.

## 🛠️ Архитектура и безопасность

* **Режим работы:** бот работает в режиме **Long Polling**. Для его работы не требуется белый IP-адрес или открытие внешних портов в сеть.
* **Надежность данных:** транзакции и пользовательские настройки сохраняются в локальной SQLite-базе данных с автоматической миграцией схемы при обновлениях.
* **Изоляция лимитов:** запросы сторонних пользователей распределяются по их персональным ключам, защищая владельца бота от лимитов `429 Too Many Requests`.
